# 武松

- 阵营：梁山阵营
- 武力：96
- 统帅：52
- 智力：72
- 政治：33

## 技能

【伏虎神威】
- 类型：步战 / 近身搏杀
- 触发：进入近身步战即可，无论徒手还是持械均可发动。
- 效果：当前武力+3。
- 常态斗将极限：99。

【血战修罗】
- 类型：绝境爆发
- 触发：真正的生死绝境、重伤血战、退无可退等极端状态。
- 效果：额外武力+6。
- 可与【伏虎神威】叠加。
- 绝境最高武力：105。

## 模型判定规则

- 武松并非统兵型人物，正规军阵与大兵团调度按统帅52处理。
- 智力72体现其较强的警觉、识人、临场判断与追查能力；不能把这些表现扩张成军师级谋略。
- 政治33，复杂行政、权力运作和长期组织治理不是其强项。

定位：绝顶级步战猛将；警觉和临场判断明显强于莽夫型人物，但军事统帅与政治能力较弱。
