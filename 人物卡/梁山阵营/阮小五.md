# 阮小五

- 阵营：梁山阵营
- 武力：84
- 统帅：55
- 智力：27
- 政治：13
- 常态陆战武力：85
- 水战峰值：90

## 技能

【短命二郎】
- 正常陆战时，当前武力+1 → 85。

【石碣悍水】
- 深水、水寨、舟船接战或水中近战时，从基础84重新计算，当前武力+6 → 90。
- 与陆战模式互斥。

【水军猛攻】
- 率小股水军强行逼近、接舷与近距离冲击时，统帅+2。

## 模型判定规则

- 陆战为二流中段；水战时必须调用90峰值和水军技能。
- 基础智政较低不影响其水战专长，专业能力不重复堆入四维。

定位：三阮中个人正面战力很强的一员，水战进入一流级特殊模式。
