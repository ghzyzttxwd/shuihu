# 燕青

- 阵营：梁山阵营
- 武力：82
- 统帅：38
- 智力：83
- 政治：78
- 常态斗将武力：83
- 相扑状态武力：90

## 技能

【浪子短打】
- 使用短兵、轻装近身或灵巧步战时，当前武力+1 → 83。

【相扑绝技】
- 进入纯徒手摔扑、擒拿、角力规则时，从基础武力82重新计算，当前武力+8 → 90。
- 该状态代表燕青在相扑、借力、破重心、擒拿方面的顶级专精，不等同于持械正面斗将达到90。
- 与【浪子短打】互斥，不叠加。

【借力卸劲】
- 相扑状态下面对依赖蛮力、重心前压、急于搂抱或强行扑压的对手时，更容易形成技术克制。
- 该技能不继续增加武力数值，而是影响相扑对抗中的招式相性与擒摔判定。

## 模型判定规则

- 智力83体现燕青突出的察言观色、应变、识人和复杂场面处理能力，但不等于大兵团军事谋略达到同档。
- 政治78主要体现交际、沟通、关系斡旋和身份场合应对；正规行政与治理能力不能无条件按78发挥。
- 统帅38，不能因为其聪明、多才多艺或在关键场合发挥重要作用，就把本人视为合格大军统帅。

定位：基础属于二流中下段，相扑达到一流门槛；真正优势在灵巧、应变、交际与多才多艺，而非统兵。
