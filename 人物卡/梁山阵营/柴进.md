# 柴进

- 阵营：梁山阵营
- 武力：80
- 统帅：50
- 智力：74
- 政治：68
- 常态斗将武力：81
- 江湖声望专项：93
- 门第交涉专项：90

## 技能

【小旋风枪棒】
- 使用枪棒等惯用兵器正常交锋时，当前武力+1 → 81。

【丹书铁券】
- 面对地方官吏、豪强、庄客，以及明显受门第身份影响的交涉场景时，按门第交涉专项90判定。
- 这是身份、门第与社会资本优势，不代表柴进具备90级治理能力。

【仗义疏财】
- 接济、收留、结交江湖人物、维持长期人脉与扩大江湖名望时，按江湖声望专项93判定。
- 声望专项可以影响招揽意愿与人情关系，但不能替代军事统帅或复杂政务能力。

## 模型判定规则

- 普通谋划、判断与应变按智力74；普通组织、行政与权力运作按政治68。
- 江湖结交与名望影响使用声望93；依赖柴氏门第、丹书铁券和身份威慑的交涉使用门第交涉90。
- 两项专项不能相加，也不能反向抬高统帅、智力或通用政治。

定位：二流下沿武人；通用军政能力并不突出，真正优势是柴氏门第、财力、江湖声望与长期人脉。
