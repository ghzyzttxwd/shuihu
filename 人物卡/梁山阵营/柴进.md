# 柴进

- 阵营：梁山阵营
- 武力：80
- 统帅：50
- 智力：78
- 政治：82
- 常态斗将武力：81
- 江湖声望专项：93
- 门第交涉专项：90

## 技能

【小旋风枪棒】
- 使用枪棒等惯用兵器正常交锋时，当前武力+1 → 81。

【丹书铁券】
- 面对地方官吏、豪强、庄客，以及明显受门第身份影响的交涉场景时，按门第交涉专项90判定。
- 这是身份、门第与社会资本优势，不代表柴进具备90级全国治理能力。

【仗义疏财】
- 接济、收留、结交江湖人物、维持长期人脉与扩大江湖名望时，按江湖声望专项93判定。
- 声望专项可以影响招揽意愿与人情关系，但不能替代军事统帅或复杂政务能力。

## 模型判定规则

- 柴进的强项是门第、财力、人脉和江湖声望，不是大兵团统帅。
- 普通治理、行政与权力运作仍看政治82；江湖结交用声望93，门第身份交涉用90。
- 专项不能互相相加，也不能拿江湖声望93去判断治国理政。

定位：二流下沿武人；梁山少数具备极强社会资本、门第资源与江湖人脉的人物。
