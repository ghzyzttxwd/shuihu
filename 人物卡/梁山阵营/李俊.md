# 李俊

- 阵营：梁山阵营
- 武力：84
- 统帅：75
- 智力：66
- 政治：70
- 常态陆战武力：85
- 水中个人战峰值：90
- 水军指挥专项：96

## 技能

【混江龙】
- 正常陆地近战时，当前武力+1 → 85。

【江河霸主】
- 江河湖泊中的水中格斗、潜游接战、夺船等场景，从基础84重新计算，当前武力+6 → 90。
- 与陆战模式互斥。

【水军都督】
- 统领水军伏击、分舟合击、诱敌入水域、截断水路、接应撤退、夺船与复杂水面调度时，按水军指挥专项96判定。
- 96代表李俊在《水浒》水军指挥领域进入真正第一档；这是水军专业能力，不代表其陆地大兵团统帅同样达到96。

## 模型判定规则

- 陆地单挑按85附近判断；普通陆地统军按统帅75。
- 江河湖泊个人战使用90水战模式；水军组织、战术调度与水面多船协同使用水军指挥96。
- 水中个人战90和水军指挥96是不同维度，不能机械相加。
- “基础统帅75”与“水军指挥96”并不矛盾：前者回答换成普通陆军后还能保持多少，后者回答进入其真正主场后的专业上限。

定位：陆战二流中段；普通陆军统帅不属于名帅，但在江河湖泊与水军体系中是梁山最核心、最成熟的第一档水军统帅。
