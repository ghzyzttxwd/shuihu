# 李俊

- 阵营：梁山阵营
- 武力：84
- 统帅：75
- 智力：66
- 政治：70
- 常态陆战武力：85
- 水中个人战峰值：90

## 技能

【混江龙】
- 正常陆地近战时，当前武力+1 → 85。

【江河霸主】
- 江河湖泊中的水中格斗、潜游接战、夺船等场景，从基础84重新计算，当前武力+6 → 90。
- 与陆战模式互斥。

【水军都督】
- 统领水军伏击、分舟合击、诱敌入水域、断后撤退时，统帅+3。

## 模型判定规则

- 不能只看基础武力84。陆地单挑按85附近判断；江河湖泊必须调用水战与水军统帅技能。
- 水战综合能力包含个人水中作战、操舟、水势判断和水军指挥。

定位：陆战二流中段；基础统帅按跨时代尺度压低，进入水军专业场景后依靠【水军都督】体现其梁山水军核心价值。
