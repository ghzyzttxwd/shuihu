# 李俊

- 阵营：梁山阵营
- 武力：84
- 统帅：75
- 智力：66
- 政治：70
- 常态陆战武力：85
- 水中个人战峰值：90
- 水军指挥专项：90

## 技能

【混江龙】
- 正常陆地近战时，当前武力+1 → 85。

【江河霸主】
- 江河湖泊中的水中格斗、潜游接战、夺船等场景，从基础84重新计算，当前武力+6 → 90。
- 与陆战模式互斥。

【水军都督】
- 统领水军伏击、分舟合击、诱敌入水域、截断水路、接应撤退与复杂水面调度时，按水军指挥专项90判定。
- 该90只用于水军专业场景，不代表李俊在陆地大兵团统帅上也有90。

## 模型判定规则

- 陆地单挑按85附近判断；普通陆地统军按统帅75。
- 江河湖泊个人战使用90水战模式，水军组织与调度使用水军指挥专项90。
- 水中个人战90和水军指挥90是不同维度，不能机械相加。

定位：陆战二流中段；梁山水军核心人物之一，在江河湖泊和水军组织调度方面具备一流专业能力。
