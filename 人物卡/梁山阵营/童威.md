# 童威

- 阵营：梁山阵营
- 武力：78
- 统帅：56
- 智力：52
- 政治：48
- 常态陆战武力：79
- 水战峰值：85
- 操舟机动专项：86

## 技能

【出洞蛟】
- 正常陆战时，当前武力+1 → 79。

【江海水手】
- 水中、舟船接战与操舟近战时，从基础78重新计算，当前武力+7 → 85。
- 与陆战模式互斥。

【操舵】
- 复杂水道、急流、夜航、追逐、撤退、抢滩、船队转向与保持舟阵机动时，按操舟机动专项86判定。
- 该专项体现童威长期在浔阳江行船、贩私盐以及担任梁山水军头领的实际经验，不等于通用统帅达到86，也不代表其具备独立设计大型水战战役的能力。

## 模型判定规则

- 陆战三流上段；水中个人接战按85判断。
- 统领普通陆军、跨兵种大兵团或独立战役时读取基础统帅56，不能因为“水军头领”身份直接抬高。
- 涉及驾船、复杂水道机动和小规模舟队协同时读取操舟机动专项86；大型水军战役总体指挥仍明显低于李俊。
- 水战武力85与操舟机动86属于不同能力，不能相加。

定位：三流上段武人；通用统帅普通，但在水中近战、操舟和复杂水道机动方面属于梁山专业水手型水军头领。
