# 《水浒同人》项目仓库

本仓库只保留当前有效设定。新规则确认后直接替换旧规则，不保留重复旧版。

## AI 最小调用原则

不要一次读取整个仓库。按任务最小化加载：

- 小说总体方向：只读 `设定/项目方向.md`
- 命数、资质、升华：只读 `设定/命数系统.md`
- 武力、武学境界：只读 `设定/武力与武学体系.md`
- 技能、斗将、回合差：只读 `设定/技能与斗将规则.md`
- 统帅、兵法：只读 `设定/兵法体系.md`
- 三国/楚汉高武对标：只读 `设定/高武后台标尺.md`
- 写某个人物：先看 `人物卡/索引.md` 找阵营，再只读该阵营索引和该人物卡；不要读取其他人物卡。

若人物卡明确写了特殊例外，以人物卡为准；否则遵守通用设定。
