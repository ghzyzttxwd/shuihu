# 《水浒同人》项目仓库

本仓库只保留当前有效设定。旧规则被新规则替换后，不保留重复旧版文件。

## AI 调用原则

1. 只读取当前任务需要的文件，不要默认把整个仓库全部加载。
2. 世界底层规则按 `设定/` 中对应模块读取。
3. 写具体人物时，只额外读取该人物的 `人物卡/姓名.md`。
4. 若人物卡与通用规则冲突，以人物卡中明确标注的“特殊例外”为准。
5. 未经确认的草案不要写入本仓库。
