# 水浒同人设定仓库

本仓库用于保存《水浒传》同人项目的设定、人物卡、规则与大纲文件。

## 正文运行规则入口

- `设定/项目方向.md`：项目总方向与四维定位。
- `设定/正文风格与商业化写作约束.md`：番茄商业化节奏、主角文风、喜剧机制、荤梗尺度与正文执行约束。
- `设定/四维属性跨时代标尺.md`：武力、统帅、智力、政治的跨时代基础数值尺度。
- `设定/武力与武学体系.md`：武力档次、武学品阶与成长规则。
- `设定/技能与斗将规则.md`：技能、专项能力、特殊战斗模式与斗将结算的唯一规则源。
- `设定/兵法体系.md`：兵法成长与统帅培养规则。
- `设定/命数系统.md`：命数获取与消耗规则。
- `设定/高武后台标尺.md`：跨时代高武比例参考。
- `人物卡/`：按阵营保存人物当前有效卡片并维护索引。

## 当前大纲

- `大纲/第一卷商业骨架.md`：第一卷24万—30万字的大阶段、商业节奏、主角成长、人物收获与最终改命结果。后续前30章章纲应在此骨架上细拆，不得另起一套第一卷方向。

## 制作参考

- `制作参考/人物卡制作与校准手册.md`：只在新建/重做人物卡、数值复核、跨阵营校准、技能与专项设计时读取。
- 正文写作、章纲推演、普通剧情续写时不要读取 `制作参考/`；直接使用当前人物卡与必要运行规则。

## 单一事实源原则

- 同一类运行规则只在一个设定文件中定义；其他文件只引用，不复制第二套同类规则。
- 新规则、新数值、新人物设定一经确定，直接替换当前对应内容。
- 模型只读取当前分支的当前文件，所有推演以当前内容为准。

## 使用原则

- 先读取当前任务相关的索引与人物卡，不递归读取全部人物卡。
- 正文创作时，人物卡中的当前四维、技能、专项和战斗模式均视为既定设定；除非用户明确要求重新校准，否则不得自行重估、改档或另造第二套数值。
- 人物基础武力、常态斗将武力、条件峰值、技能与专项能力分开处理。
- 道法、水战、火器、潜行、医术等特殊能力不能仅以基础武力或通用智力替代判断。
- 章纲与正文若涉及商业节奏、主角吐槽、喜剧、低俗梗、性暗示和严肃场景切换，统一以 `设定/正文风格与商业化写作约束.md` 为准。
- 第一卷剧情推进统一以 `大纲/第一卷商业骨架.md` 为上位大纲；后续逐章章纲只负责细化，不得无授权改变卷级结果。
