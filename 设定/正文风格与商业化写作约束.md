# 正文风格与商业化写作约束

本文件用于约束后续章纲设计、正文生成与写手智能体。目标平台以番茄小说男频为主，商业化、追读和阅读体验优先，但不得牺牲已经确定的世界设定、人物逻辑和战力体系。

## 一、总体定位

- 类型：轻松爽感的《水浒》同人争霸文。
- 核心原则：正经世界 + 轻松主角 + 爽文节奏。
- 世界、战争、人物动机和势力运行逻辑必须认真；主角本人不苦大仇深，不写成长期沉着脸分析局势的严肃历史文主角。
- 水浒味必须保留：江湖气、人物称呼、武将斗将、山寨与庄寨关系、原著人物性格和原著因果都要成立。
- 不追求仿古文。正文以现代白话为主，对话根据人物身份适量保留古代和江湖语感。

## 二、番茄商业化原则

- 大主线可以慢，单章反馈不能慢。
- 不要求每章都打架、杀人或升级，但连续数章不能没有新变化。
- 常见有效反馈包括：
  - 主角武力、武学、技能成长；
  - 原著人物态度变化；
  - 招揽、争夺或改变人物命运；
  - 敌我关系改变；
  - 原著剧情被改写；
  - 坑敌成功、敌人翻车或破防；
  - 地位、权力、资源、情报变化；
  - 一场斗将、小战、谋局取得明确结果。
- 前期避免长时间纯解释、纯开会、纯盘点、纯制度建设。
- 三庄整合、军政建设属于长线卖点，必须通过具体人物、利益冲突、事件和胜负推进，不能写成“改革报告”。
- 第一阶段要持续兑现水浒IP：熟悉人物、熟悉矛盾、熟悉命运必须较早出现并产生新变化。

## 三、祝彪主角性格

### 1. 核心气质

祝彪是现代人穿越者。

核心概括：

**外正内皮，嘴上一本正经，心里骚话不断；能装、会坑、有点损，但关键时候靠谱。**

### 2. 对外表现

- 在祝朝奉、栾廷玉、李应、庄中长辈、官面人物面前，懂礼数、懂身份、会维持祝家三郎和少庄主应有的体面。
- 正式场合可以表现得年轻英武、沉稳、有分寸，必要时会故意装正经、装高深、装胸有成竹。
- 不因为是现代穿越者就在人前大量说现代词、网络梗。
- 古人应当觉得他“变得聪明、会做人、有手腕”，而不是觉得他像一个现代网友突然掉进宋代。

### 3. 内心状态

- 内心始终保留鲜明现代人视角。
- 吐槽欲强，对古代习俗、原著名场面、人物行为、自己遭遇的离谱处境都会产生现代式腹诽。
- 可以有现代网络感，但不要写成弹幕体。
- 主角不是纯逗比、话痨或小丑；吐槽服务人物性格和节奏，不抢夺剧情本体。

### 4. 做事风格

- 喜欢占便宜，但不是贪生怕死。
- 怕麻烦，但不怕事。
- 喜欢用脑子坑人，尤其喜欢让敌人自以为得计后一步步掉进坑里。
- 对敌人有一定恶趣味，乐于看敌人翻车、破防、社死、误判、狼狈收场。
- 真正面对斗将、战争、生死、重大失败和重大决策时，会迅速认真，不强行插科打诨。
- 对自己人总体靠谱，有正常的喜怒、感情和责任感，不塑造成冷冰冰的争霸机器。

## 四、喜剧与爽点的主要来源

### 1. 表里反差

- 主角表面一本正经，内心完全是现代人频道。
- 外部越正式，内心反差越容易形成笑点。

### 2. 敌人翻车

- 敌人可以被整、被坑、被误导、被诱导犯错、被迫社死或狼狈收场。
- 重点是“敌人认真地倒霉”，而不是作者强行把敌人写成傻子。
- 优先利用：信息差、性格弱点、利益诱惑、立场冲突、错误判断、提前布置。

### 3. 人物反应链

一个有效桥段应尽量形成：

主角行动 → 对方反应 → 主角内心吐槽 → 误会或判断变化 → 人物关系/局势变化 → 新问题或新爽点。

笑点和剧情推进尽量绑定，不单独停下来讲段子。

### 4. 水浒原著梗

- 可利用原著人物性格、名场面、黑历史、未来命运制造会心一笑。
- 原著梗必须让剧情和人物更鲜活，不能变成网络梗大杂烩。

### 5. 兄弟、男女与日常互动

- 祝龙、祝虎、栾廷玉、扈三娘以及以后加入的好汉，都应形成不同的互动喜剧模式。
- 不允许所有笑点都只靠祝彪一个人不停说骚话。

## 五、低俗梗、荤梗与性暗示

- 允许适量低俗梗、荤梗、身体梗、性暗示、男女暧昧和男人之间的损话。
- 这些内容属于番茄商业化阅读中的调味和情绪工具，不需要为了所谓“高级感”主动删净。
- 可主要用于：
  - 主角内心吐槽；
  - 男女互动与暧昧；
  - 兄弟互损；
  - 对敌人的缺德整蛊；
  - 反差笑点。
- 控制重点不是“绝对尺度”，而是避免重复、油腻和喧宾夺主。
- 同一个荤梗或低俗梗不要连续反复使用。
- 严肃战斗、真实死亡、重大悲剧情节中应适时收住，不要用黄色笑话破坏情绪。

## 六、文风执行

- 正文以现代白话为主，句子整体偏短，信息和人物反应密度高。
- 对话应自然、直接，有人物身份差异。
- 水浒人物可以使用“哥哥、教头、庄主、好汉、泼贼、撮鸟、洒家”等符合身份的江湖或时代称呼，但不要句句仿古。
- 主角内心可更现代、更损、更轻松。
- 避免长段连续分析；复杂判断尽量拆进动作、对话、人物反应和结果。
- 战斗场景以紧张、力量感、武艺差距、临场判断为主；真正进入斗将后降低搞笑密度。

## 七、敌人智商与人物逻辑

- 禁止为了爽点把宋江、吴用、李应、栾廷玉、梁山头领、官军将领等写成集体降智。
- 敌人中计必须有可解释的原因。
- 主角可以凭原著记忆和现代视角占先机，但原著被改动以后，未来必须逐渐变得不可预测。
- 敌人一旦意识到主角的套路，应当学习、调整和反制。
- 爽点来自主角更早掌握信息、更会利用人性和局势，而不是来自全世界突然变蠢。

## 八、参考风格

可参考《水浒：狗官，你还说你不会武功？》的以下结构性特点：

- 正经水浒世界里放一个现代思维、吐槽强烈的穿越主角；
- 笑点与剧情推进绑定；
- 高频人物反应与误会链；
- 主角坑人后让敌人或配角产生连续情绪反馈；
- 正式战斗时能切回紧张与热血。

只参考节奏、喜剧机制和叙事结构，不照搬具体台词、桥段、口癖、系统设定或人物关系。

## 九、最终观感目标

祝彪给读者的总体感觉应当是：

**“这人挺损、挺骚、挺有意思，平时看着不太正经；但真遇到事，他是真能扛、真能打、真能办成。”**

整本书的总体阅读感受应当是：

**有水浒味、有斗将、有争霸、有原著人物命运改写，同时轻松、好笑、情绪反馈快，读起来不累。**
