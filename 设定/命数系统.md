# 命数系统

外挂核心为【命数】。

## 主要用途

1. 武学升华。
2. 提升资质。
3. 兵法升华。

日常练武、读兵书、实战仍需本人完成。系统不直接灌顶，不凭空生成军队、名将、粮草或超时代科技。

## 命数奖励尺度

同一因果链不得拆分重复刷命数；可以阶段预支，最终按整个改命事件总价值补差额。

- 小型改命：1
- 重要人物命运改变：2—3
- 重要原著剧情改写：4—6
- 核心主线节点改写：7—10
- 一地格局发生根本变化：12—20
- 山东/一方天下格局改变：25—40
- 靖康、王朝兴亡级：50—100

## 武学升华消耗

- 寻常武艺 → 上乘武学：2命数
- 上乘武学 → 绝学：5命数
- 绝学 → 顶级绝学：12命数
- 顶级绝学 → 镇世绝学：30命数以上，并且必须满足镇世条件

## 资质提升消耗

- 普通 → 良好：5命数
- 良好 → 上等：10命数
- 上等 → 天才：20命数
- 天才 → 绝世：40命数

资质主要影响学习、理解、修炼、兵法掌握效率，不直接等同于基础武力增加。
