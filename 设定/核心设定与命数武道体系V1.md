# 《水浒同人》核心设定与命数武道体系 V1

> 本文件记录当前已经确认的底层规则。未确认的人物数值、具体技能、剧情大纲等不在本文件擅自补完。

## 1. 项目基础方向

- 主角：祝彪。
- 核心路线：个人武力成长 + 《水浒》本土人物争夺/招揽 + 势力成长 + 后期天下争霸。
- 不召唤其他世界人物。
- 四维属性：武力、统帅、智力、政治。
- 面板属于爽点。属性提升、技能获得、重大突破后可以明确展示完整/局部面板，但不需要每章反复弹出。

## 2. 外挂核心：命数

取消“天道酬勤”，外挂核心统一为【命数】。

### 2.1 命数主要用途

1. 武学升华。
2. 提升资质。
3. 后续兵法升华可沿用同类规则。

日常练武、读兵书、实战仍然需要本人完成，系统不直接灌顶，不凭空生成军队、名将、粮草或超时代科技。

### 2.2 命数奖励尺度

同一因果链不得拆分重复刷命数；可以阶段预支，最终按整个改命事件的总价值补差额。

- 小型改命：1
- 重要人物命运改变：2—3
- 重要原著剧情改写：4—6
- 核心主线节点改写：7—10
- 一地格局发生根本变化：12—20
- 山东/一方天下格局改变：25—40
- 靖康、王朝兴亡级：50—100

### 2.3 武学升华消耗

- 寻常武艺 → 上乘武学：2命数
- 上乘武学 → 绝学：5命数
- 绝学 → 顶级绝学：12命数
- 顶级绝学 → 镇世绝学：30命数以上，并且必须满足镇世条件

### 2.4 资质提升消耗

资质是长期复利型强化，因此价格高于普通武学升华。

- 普通 → 良好：5命数
- 良好 → 上等：10命数
- 上等 → 天才：20命数
- 天才 → 绝世：40命数

资质主要影响学习、理解、修炼和兵法掌握效率，不直接等同于基础武力增加。

## 3. 武力定义与五档体系

武力是人物常态综合战斗能力的最终数值，包含其武艺、身体、战斗经验等综合表现。

基础武力95正常强于基础武力94。技能发动后可以临时改变当前武力。

不单独设置力量、反应、骑术等子属性。正常武将默认具备与身份匹配的娴熟骑术；但“特别擅长马战”可以形成独立技能。

### 五档

- 不入流：69及以下
- 三流：70—79
- 二流：80—89
- 一流：90—94
- 绝顶：95—100

94为一流巅峰，95是进入绝顶的门槛。

《水浒》常规武道基础天花板为100。卢俊义可达到基础武力100，为水浒第一人级标尺。

技能发动后的实际武力允许突破100。

## 4. 武学：品阶与掌握境界

### 4.1 武学品阶

寻常武艺 → 上乘武学 → 绝学 → 顶级绝学 → 镇世绝学

### 4.2 掌握境界

入门 → 小成 → 大成 → 圆满

品阶与掌握境界是两条不同维度，例如“上乘武学·大成”“绝学·小成”均成立。

### 4.3 上乘、绝学、顶级绝学成长标尺

上乘武学：
- 入门：70—74
- 小成：75—79
- 大成：80—84
- 圆满：85—89

绝学：
- 入门：75—79
- 小成：80—84
- 大成：85—89
- 圆满：90—94
- 绝学最高只能支撑到基础武力94，即一流巅峰；不能仅靠继续打磨绝学突破95。

顶级绝学：
- 入门：80—84
- 小成：85—89
- 大成：90—94
- 圆满：95—100
- 只有掌握顶级绝学并达到圆满层次，才正式进入绝顶武将区间；95为绝顶起点，之后可继续精进至100。

以上区间是正常成长标尺，不是死板的反向验算公式。升品带来的固定武力跃迁可能让人物当前数值短暂高于新境界的典型区间，但掌握境界仍按“固定下降一级”计算。

### 4.4 升品规则

寻常→上乘、上乘→绝学、绝学→顶级绝学，不要求原武学先达到圆满；只要命数足够即可升华。

升品后，掌握境界固定下降一级：
- 圆满 → 大成
- 大成 → 小成
- 小成 → 入门
- 入门 → 入门

原有武学积累不会清零。

升品瞬间固定增加基础武力：
- 寻常 → 上乘：+1
- 上乘 → 绝学：+2
- 绝学 → 顶级绝学：+3
- 顶级绝学 → 镇世绝学：+4

升品后仍可继续正常修炼、提高基础武力。

## 5. 镇世绝学

顶级绝学可以把常规基础武力推到100。

基础武力要真正突破100，必须走出独属于自己的武道，创造【镇世绝学】。镇世绝学不是“顶级秘籍再高一级”，而是类似玄幻中真正走出自己的道，和人物身体、性格、经历、战斗方式高度绑定。

镇世绝学本身也有强弱。

### 镇世之路

- 顶级绝学达到圆满、人物约从基础武力95开始，即开启严格的镇世条件。
- 95→100阶段，人物可以一边继续精进基础武力，一边完成镇世条件，保持长期成长盼头。
- 真正完成顶级绝学→镇世绝学的最终升华，要求：基础武力100 + 顶级绝学圆满 + 镇世条件全部完成 + 足够命数。
- 完成镇世升华后，基础武力固定+4，即100→104起步。
- 之后镇世绝学仍可继续成长；常规基础武力理论最高暂定110。

三国、楚汉等更高武道时代只作为后台世界观标尺，不在当前《水浒》正文提前展开。

当前后台参考可暂记：马超等约104，关羽/张飞约105，吕布约106，李存孝约109，项羽约110；技能另算，未来可调整。

## 6. 技能体系

原“特性”统一改称【技能】。

- 一个角色可以拥有多个技能。
- 技能可以增加武力、统帅、智力、政治，也可以具有特殊机制。
- 技能能否叠加完全取决于触发条件；条件同时成立即可叠加，条件互斥则不能叠加。
- 不设置统一技能数量上限。
- 不设置统一技能总增幅上限。
- 基础武力100并不限制技能爆发，技能发动后的实际武力可以明显突破100。
- 高层人物的技能强度可以远高于普通技能。

花荣明确不仅拥有射术方向技能，也拥有马战方向技能；具体名称与数值后续单独设计。

武学升品可带来新技能或已有技能蜕变；技能应体现人物、武学和实战经历，不做模板化批量技能。

## 7. 斗将规则 V1

斗将差值使用【当前实际武力】，即基础武力加上当前已经触发且可叠加的技能增幅。

以下回合数为常态参考，不是绝对物理法则；特殊技能、伤势、兵器克制、偷袭等可以改变结果。

- 差0点：伯仲之间，常见百合以上难分胜负。
- 差1—2点：小幅优势，通常约60—120合决出明显优劣。
- 差3—4点：明显优势，通常约30—60合。
- 差5—6点：强势压制，通常约15—30合。
- 差7—8点：近乎碾压，通常约8—15合。
- 差9—11点：巨大差距，通常数合内重创或斩杀，约3—8合。
- 差12点及以上：秒杀级差距，通常一合级解决；极少数特殊情况可拖到数合。

爆发技能可以在某一瞬间把差距推入更高档，因此关羽一类极端爆发技能可以形成瞬间秒杀窗口。具体三国斗将规则以后再单独细化。

## 8. 兵书 / 兵法体系（从简版）

统帅不是本书第一爽点，因此兵法体系采用与武学兼容但更简洁的版本，避免抢走斗将主线。

- 兵法品阶：寻常兵法 → 上乘兵法 → 兵家绝学 → 顶级兵法。
- 掌握境界同样使用：入门 → 小成 → 大成 → 圆满。
- 读兵书、军阵推演、实际练兵、战场指挥都可以推动理解和统帅成长。
- 命数可用于兵法升华，价格暂沿用武学同级升华尺度。
- 兵法升品时统帅固定增幅参考：寻常→上乘+1，上乘→兵家绝学+2，绝学→顶级+3。
- 不规定“每次兵法升华必得技能”。只有人物真正形成鲜明军略、完成重大实战验证时，才凝结统帅类技能。
- 统帅100视为正常兵法极境；若未来真出现“兵仙在世”级人物，可另开自创军略/兵仙之道，当前不展开。

## 9. 祝彪初始面板 V1

### 基础属性

- 武力：84
- 统帅：73
- 智力：80
- 政治：72

定位：武力已经达到二流高段，但长期卡在84，迟迟无法突破85；真正进入上乘武学圆满层次，是开局最直接的个人成长目标之一。

### 资质

- 资质：上等

### 初始武学

- 【祝氏六合枪】
- 品阶：上乘武学
- 境界：大成
- 当前状态：武力84，长期卡在85之前

### 初始技能

【六合争雄】

- 类型：斗将 / 枪术技能
- 触发：持长枪与单将正面斗将。
- 效果：当前武力+2；若对手当前基础武力高于祝彪，则额外+1。
- 最高增幅：+3。

该技能体现祝彪本身已有不错的枪术天赋和正面斗将能力，但不会让开局84的祝彪直接跨级碾压一流高手。

- 祝氏六合枪后续升华后的绝学、顶级绝学正式名称。
- 镇世条件的完整任务清单。
- 三国、楚汉人物的最终技能与正式斗将体系。
