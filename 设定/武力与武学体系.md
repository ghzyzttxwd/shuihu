# 武力与武学体系

## 武力定义

武力是人物常态综合战斗能力的最终数值，包含武艺、身体、战斗经验等综合表现。

基础武力95正常强于基础武力94。技能发动后可以临时改变当前武力。

不单独设置力量、反应、骑术等子属性。正常武将默认具备与身份匹配的娴熟骑术；特别擅长马战时通过技能体现。

## 五档武力

- 不入流：69及以下
- 三流：70—79
- 二流：80—89
- 一流：90—94
- 绝顶：95—100

94为一流巅峰，95是绝顶门槛。

《水浒》常规武道基础天花板为100。卢俊义基础武力100，作为水浒第一人级标尺。技能发动后的实际武力允许突破100。

徐宁基础武力94，作为一流上沿标尺。能在正常正面斗将中明确压过或较快击败徐宁的人，通常进入95+绝顶范围。

## 武学品阶

寻常武艺 → 上乘武学 → 绝学 → 顶级绝学 → 镇世绝学

## 掌握境界

入门 → 小成 → 大成 → 圆满

品阶与掌握境界是两条不同维度，例如“上乘武学·大成”“绝学·小成”均成立。

## 成长标尺

### 上乘武学
- 入门：70—74
- 小成：75—79
- 大成：80—84
- 圆满：85—89

### 绝学
- 入门：75—79
- 小成：80—84
- 大成：85—89
- 圆满：90—94
- 绝学最高支撑到基础武力94，即一流巅峰。

### 顶级绝学
- 入门：80—84
- 小成：85—89
- 大成：90—94
- 圆满：95—100
- 顶级绝学达到圆满后进入绝顶区间，95为起点，可继续精进至100。

以上区间是正常成长标尺，不作为反向验算人物卡的机械公式。

## 升品规则

寻常→上乘、上乘→绝学、绝学→顶级绝学，不要求原武学先圆满；命数足够即可升华。

升品后掌握境界固定下降一级：
- 圆满 → 大成
- 大成 → 小成
- 小成 → 入门
- 入门 → 入门

原有武学积累不会清零。

升品瞬间固定增加基础武力：
- 寻常 → 上乘：+1
- 上乘 → 绝学：+2
- 绝学 → 顶级绝学：+3
- 顶级绝学 → 镇世绝学：+4

## 镇世绝学

顶级绝学可以把常规基础武力推到100。基础武力要真正突破100，必须走出独属于自己的武道并创造【镇世绝学】。

镇世绝学不是单纯更高一级秘籍，而是和人物身体、性格、经历、战斗方式高度绑定的个人武道。

### 镇世之路
- 顶级绝学达到圆满、人物约从基础武力95开始，即开启严格的镇世条件。
- 95→100阶段，可以一边继续提升基础武力，一边完成镇世条件。
- 完成顶级绝学→镇世绝学要求：基础武力100 + 顶级绝学圆满 + 镇世条件全部完成 + 足够命数。
- 镇世升华后基础武力固定+4，即100→104起步。
- 此后镇世绝学仍可继续成长。
