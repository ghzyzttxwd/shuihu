# 四维属性统一标尺

本文件用于统一人物卡中的【武力、统帅、智力、政治】基础属性，防止不同批次人物出现随手填值、职业能力污染通用属性、或为了“跨时代压缩”把《水浒》真正的顶尖人物整体压低。

## 一、总原则

1. 四维基础值使用统一跨时代尺度，不只在《水浒》内部自循环。
2. 《水浒》某一维度真正的绝对顶级人物，可以达到95～100；这个区间大致对应三国体系的一流人物，而不是诸葛亮、司马懿、吕布等跨时代绝对天花板。
3. 三国等更高人才密度时代的绝对顶级人物允许基础值超过100，并继续叠加技能。
4. 不能因为“《水浒》整体人才较弱”就把该作品每个维度的第一人压到八十多；同样，也不能因为某人是梁山头领、名将、军师或专业人才，就机械给高四维。
5. 基础属性表示通用能力；职业、兵种、环境、技术、身份、道法等狭窄领域的极强能力，原则上用技能、专项或特殊模式表达。

## 二、基础属性区间

- 101以上：跨时代超一流或绝对顶级人物；《水浒》常规非武力四维原则上极少出现。
- 95～100：一流。放在《水浒》中，只给该维度真正最顶尖、足以放到三国仍算一流的人物。
- 90～94：准一流 / 顶尖。作品内部明显位于最前列，但跨时代仍略低于真正一流。
- 80～89：优秀。明显强于一般人物，能够稳定承担较高难度任务。
- 70～79：良好 / 能干。具备较成熟能力，但不是名家级人物。
- 60～69：普通偏上。存在一定经验、常识或实务能力。
- 50～59：普通或略弱。能完成基础事务，但缺乏突出表现。
- 40～49：明显偏弱。
- 30～39：很弱。
- 29及以下：该维度显著短板。

注意：这些区间是能力层级，不是身份等级。某人地位很高，不代表统帅、智力、政治必须高；某人四维很低，也不代表其专业技能没有战略价值。

## 三、四维定义

### 武力

表示无特殊环境、无专用外挂条件下的个人常规战斗基础，包括力量、技巧、反应、耐力、兵器掌握与实战综合。

- 兵器专精、弓箭、暗器、水战、相扑、法术等可以从基础武力另开模式或技能。
- 武力高不能自动带高统帅。

### 统帅

表示真正的带兵和战场组织能力，重点看：

- 能控制多大规模的兵力；
- 能否独立领军；
- 队伍纪律、阵形和临阵控制；
- 多部队协同、攻守转换和持续作战；
- 是否有稳定的实际统军表现。

不等同于：个人武力、军师谋略、官职、教头身份、山寨头领身份。

兵种或环境专精可以另列，如【连环马统御】【水军指挥】【钩镰军训练】。

### 智力

表示通用谋划、判断、识计、应变、学习、推理和理解复杂局面的能力。

不等同于：医术、兽医、书法、篆刻、炮术、造船、财会、锻造、道法等专业技术。

专业技术即使达到95～100，也不能反推基础智力同样达到95～100。

### 政治

表示通用的组织治理、行政、人事、制度、利益协调、外交谈判和长期权力运作能力。

不等同于：单纯名望、江湖义气、家世身份、会做人、经营一家酒店、熟悉牢狱流程或某项文书技术。

声望、人情、门第、刑名、庄务、酒店经营等可做专项；只有能稳定外推到更广泛组织治理场景的能力，才进入基础政治。

## 四、基础值与专项的关系

1. 基础值回答“换一个普通场景，他还能不能保持这个水平”。
2. 专项回答“进入这个人的主场，他能达到什么层级”。
3. 专项可以高于基础值很多，例如：
   - 安道全通用智力不高，但医术可以接近100；
   - 凌振通用智力不必很高，但炮术可以接近100；
   - 公孙胜通用智力不必等同顶级军师，但道法、破法可以接近或达到100；
   - 燕青普通政治不必很高，但人情斡旋可以达到高等级；
   - 李俊普通陆军统帅不必是名帅，但水军指挥可以进入《水浒》第一档。
4. 专项不是默认叠加。若人物卡没有明确写“可叠加”，模型应选择当前场景最相关的基础值、技能或专项进行判定。

## 五、顶尖人物稀缺原则

95以上必须稀缺，但不能人为清空。

- 智力：吴用属于《水浒》最明确的一流候选；朱武等人可根据通用谋略与专项分别处理。
- 统帅：宋江的梁山总体统筹、呼延灼的正规军与重骑统御、关胜等正规大将，需要区分“通用统帅”和“兵种/组织专项”，不能一律压成八十出头，也不能全部塞进95以上。
- 政治：宋江的招揽、整合、人事与长期组织路线是梁山最强候选；柴进的门第与江湖声望应更多通过专项体现。

## 六、校准优先级

具体人物校准按以下顺序：

1. 原著明确战绩、统军、谋划、治理与专业表现；
2. 原著中的相互评价、职位实际职责和长期表现；
3. 轩辕春秋等成熟旧评作为相对排序参考；
4. 本项目既有标尺和人物间相互约束。

论坛或游戏数据不能机械照搬；同样，本项目也不能为了和旧数据不同而故意反着改。

## 七、禁止事项

- 禁止为了“看起来均衡”随手把统智政填在60～79。
- 禁止职业专家自动获得高智力。
- 禁止名将自动获得高统帅。
- 禁止江湖名望自动获得高政治。
- 禁止军师自动获得高统帅。
- 禁止为了跨时代比较，把《水浒》某维度真正第一人整体压到八十多。
- 禁止仅凭单一头衔决定数值；必须看其实际表现和可外推能力。
