# 项目方向

- 主角：祝彪。
- 核心路线：个人武力成长 + 《水浒》本土人物争夺/招揽 + 势力成长 + 后期天下争霸。
- 不召唤其他世界人物。
- 四维属性：武力、统帅、智力、政治。
- 面板属于爽点。属性提升、技能获得、重大突破后可以明确展示完整或局部面板，但不需要每章反复弹出。
- 本书最重要的爽点之一是斗将与个人武力成长；统帅、智力、政治作为重要辅助维度，但不应喧宾夺主。

## 主角中期成长锚点

- 独龙岗主线终局约在第50章左右时，祝彪基础武力目标控制在91—92。
- 该阶段不提前进入95+绝顶层级，为曾头市、大名府及后续田虎、王庆、方腊等篇章保留持续成长空间。
- 越级击败更强武将时，优先通过既有技能、兵器与招式克制、地形、阵法和战术完成，不以临时硬抬基础武力作为默认解决方案。
