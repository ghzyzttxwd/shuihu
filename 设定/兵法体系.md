# 兵法体系

统帅不是本书第一爽点，因此兵法体系采用与武学兼容但更简洁的版本，避免抢走斗将主线。

- 兵法品阶：寻常兵法 → 上乘兵法 → 兵家绝学 → 顶级兵法。
- 掌握境界：入门 → 小成 → 大成 → 圆满。
- 读兵书、军阵推演、实际练兵、战场指挥都可以推动理解和统帅成长。
- 命数可用于兵法升华，价格沿用武学同级升华尺度。
- 兵法升品时统帅固定增幅参考：寻常→上乘+1，上乘→兵家绝学+2，绝学→顶级+3。
- 不规定每次兵法升华必得技能；只有人物真正形成鲜明军略、完成重大实战验证时，才凝结统帅类技能。
- 统帅100视为正常兵法极境；若未来真出现“兵仙在世”级人物，可另开自创军略/兵仙之道，当前不展开。
